# CozyCoffee
Coffee shop POS for the Pluralsight LTCA Custom Shop capstone project. 

This gave me more trouble than I was expecting! 
This is a coffee shop POS (self checkout?) application that allows the user to add drinks, and other products, specify options, and see their basket. 
Once you've finished an order, you can check out, and decide if you want a receipt file printed. 
Also! You can play any .wav music file on your computer! 
Lofi hip-hop is recommended for cozy/chill vibes.
